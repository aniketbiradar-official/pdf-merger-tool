# PDF Merger Tool (Python)

This is a simple Python GUI application that merges multiple PDF files into a single PDF.

The user selects a folder, and all PDF files inside that folder are merged automatically.

---

## Features
- Simple graphical interface
- Merge all PDFs in a selected directory
- Error handling
- Log file generation

---

## Technologies Used
- Python
- Tkinter
- PyPDF2
